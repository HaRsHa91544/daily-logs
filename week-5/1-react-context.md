# Today, I learnt about why React Context exists.

## When you want to pass the data from a parent to a deeper child component inside it. We need to pass it through props to all intermediate components unnecessarily to receive by the deeper child component. This problem is called ``props drilling``.

## To solve that problem React introduced Context where a parent data can be shared to it child components without passing the data through props in the intermediate components.
