# Today, I learnt about why we need to use useRef hook in React.

## Actually, the useState hook allows the state to persist between re-renders and also synchronizing the UI with the state.

## Whereas the useRef allows the state to persist between re-renders but it doesn't synchronize with the UI automatically (doesn't cause re-renders).
